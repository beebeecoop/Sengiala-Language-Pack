# Import Reports

CSV reports generated by `scripts/import-excel-translations.py` can be written here during local work.

Example report filename:

```text
import-excel-translations-YYYYMMDD-HHMMSS.csv
```

Typical statuses:

```text
would_update
updated
would_add
added
skipped_same_value
skipped_unmapped
skipped_empty_key
skipped_empty_value
duplicate_input
```

Review the report before running the script in `--mode apply`.

Generated CSV reports normally do not need to be committed unless they are being preserved as formal test evidence.
