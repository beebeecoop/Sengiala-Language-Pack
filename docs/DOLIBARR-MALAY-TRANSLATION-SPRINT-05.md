# Dolibarr Malay Translation Sprint 05

## Purpose

Sprint 05 expands the Bahasa Melayu Malaysia language pack for stock, warehouse, shipment, delivery, reception, logistics, and supplier proposal workflows.

This sprint builds on Sprint 01, Sprint 02, Sprint 03, and Sprint 04 terminology decisions and must preserve the approved controlled terminology in `docs/TERMINOLOGY-STANDARD.md`.

## Scope

Sprint 05 focuses on:

- Stock
- Warehouse / store
- Shipment
- Delivery
- Reception
- Logistics
- Supplier proposal workflow
