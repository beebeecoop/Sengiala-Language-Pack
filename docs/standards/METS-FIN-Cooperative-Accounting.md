# METS-FIN — Malaysian Cooperative Accounting Terminology

## 1. Tujuan

Dokumen induk ini menghimpunkan istilah normatif bagi domain kewangan, perakaunan, perbankan dan pelaporan koperasi dalam Sengiala-Language-Pack serta SengialaSuite.

## 2. Status Dokumen

- Versi: 0.1
- Status: Draf Aktif
- Domain: FIN
- Pelaksanaan awal: Dolibarr 23.0 dan SengialaSuite Finance Foundation

## 3. Kaedah Rekod

Setiap keputusan menggunakan ID kekal `FIN-0000`. ID tidak berubah apabila istilah disemak. Perubahan direkodkan melalui versi dan status kitar hayat.
