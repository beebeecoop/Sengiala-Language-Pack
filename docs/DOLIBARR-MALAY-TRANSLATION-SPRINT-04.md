# Dolibarr Malay Translation Sprint 04

## Purpose

Sprint 04 expands the Bahasa Melayu Malaysia language pack for document handling, files, attachments, notes, import/export, reports, and PDF-related labels.

This sprint builds on Sprint 01, Sprint 02, and Sprint 03 terminology decisions and must preserve the approved controlled terminology in `docs/TERMINOLOGY-STANDARD.md`.

## Scope

Sprint 04 focuses on:

- Documents
- Files and attachments
- ECM / document storage
- Notes
- Import
- Export
- Reports
- PDF labels and actions

## Target Files

- `lang/ms_MY/documents.lang`
- `lang/ms_MY/files.lang`
- `lang/ms_MY/ecm.lang`

- `lang/ms_MY/import.lang`
