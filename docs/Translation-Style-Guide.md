# Panduan Gaya Terjemahan

## Bahasa dan nada

Gunakan Bahasa Melayu Malaysia yang:

- jelas;
- ringkas;
- profesional;
- sesuai untuk antara muka ERP;
- mudah difahami oleh pengguna koperasi.

Elakkan ayat terlalu panjang, bahasa pasar dan terjemahan literal yang janggal.

## Huruf besar

Gunakan huruf besar hanya untuk:

- nama modul;
- nama dokumen rasmi;
- tajuk;
- singkatan rasmi.

Label biasa menggunakan gaya ayat, contohnya `Tarikh invois`, bukan `Tarikh Invois`, kecuali konvensyen antara muka asal memerlukannya.

## Istilah yang dikekalkan

Istilah teknikal antarabangsa boleh dikekalkan apabila terjemahannya mengurangkan kefahaman, tetapi penggunaannya mesti konsisten dan direkodkan dalam glosari.

## Pemegang tempat

Jangan ubah:

- `%s`, `%d`, `%1$s`;
- `{0}`, `{1}`;
- tag HTML;
- entiti HTML;
- nama pemboleh ubah;
- kod atau laluan fail.

## Terjemahan berasaskan konteks

Semak modul dan tindakan sebenar sebelum menterjemah. Contoh:

- `Share` sebagai modal → `Modal Syer`;
- `Share` sebagai bonus → `Syer Bonus`;
- `Share` sebagai tindakan aplikasi → `Kongsi`.

## Kata kerja antara muka

Gunakan kata kerja ringkas:

- Add → Tambah
- Edit → Sunting
- Delete → Padam
- Save → Simpan
- Cancel → Batal
- Validate → Sahkan
- Close → Tutup
- Send → Hantar
- Search → Cari
- Print → Cetak
- Download → Muat turun
- Upload → Muat naik

## Semakan kualiti

Setiap fail perlu diperiksa untuk:

1. kunci pendua;
2. kunci tanpa terjemahan;
3. pemegang tempat yang hilang;
4. istilah yang bercanggah dengan SPS-004;
5. ejaan dan tatabahasa;
6. kesesuaian dalam paparan Dolibarr.
