# Dolibarr Malay Translation Sprint 09

## Purpose

Sprint 09 enhances the Bahasa Melayu Malaysia language pack for project management, agenda, notification, system administration, configuration, and module builder terminology.

This sprint builds on Sprint 01 to Sprint 08 terminology decisions and must preserve all approved controlled terminology.
