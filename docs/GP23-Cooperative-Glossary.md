# Glosari GP23 dan Koperasi

Dokumen ini merekodkan padanan istilah utama bagi pelaporan kewangan dan operasi koperasi Malaysia.

| English | Bahasa Melayu | Catatan |
|---|---|---|
| Member | Anggota | Istilah rasmi bagi anggota koperasi |
| Membership | Keanggotaan | Status dan pengurusan anggota |
| Share Capital | Modal Syer | Modal yang disumbangkan anggota |
| Bonus Share | Syer Bonus | Syer yang diterbitkan sebagai bonus |
| Patronage | Potongan Langganan | Pulangan berdasarkan langganan atau urus niaga anggota |
| Patronage Bonus | Bonus Langganan | Bonus berkaitan langganan anggota |
| Balance Sheet | Kunci Kira-Kira | Penyata kedudukan kewangan koperasi |
| Income Statement | Penyata Untung atau Rugi | Penyata prestasi kewangan |
| Cash Flow Statement | Penyata Aliran Tunai | Aliran masuk dan keluar tunai |
| Appropriation | Pembahagian Keuntungan | Pembahagian lebihan atau keuntungan selepas keputusan yang berkaitan |
| Appropriation Account | Akaun Pembahagian Keuntungan | Akaun bagi merekod pembahagian keuntungan |
| Chart of Accounts | Carta Akaun | Senarai akaun berstruktur |
| General Ledger | Lejar Am | Rekod keseluruhan akaun |
| Trial Balance | Imbangan Duga | Ringkasan baki debit dan kredit |
| Journal | Jurnal | Catatan transaksi perakaunan |
| Journal Entry | Catatan Jurnal | Catatan debit dan kredit |
| Financial Year | Tahun Kewangan | Tempoh pelaporan kewangan |
| Opening Balance | Baki Awal | Baki pada awal tempoh |
| Closing Balance | Baki Akhir | Baki pada akhir tempoh |
| Surplus | Lebihan | Lebihan hasil berbanding belanja |
| Deficit | Kurangan | Kurangan hasil berbanding belanja |
| Reserve Fund | Kumpulan Wang Rizab | Rizab koperasi |
| Dividend | Dividen | Agihan atas modal syer, tertakluk keputusan dan peraturan |
| Contribution | Caruman | Sumbangan berkala atau ditetapkan |
| Subscription | Langganan | Bayaran atau urus niaga berkaitan anggota |

## Nota normatif

Istilah dalam dokumen ini hendaklah digunakan bersama SPS-004. Sebarang padanan baharu perlu dinilai mengikut konteks sebenar modul dan tidak boleh menggantikan istilah normatif tanpa semakan.
