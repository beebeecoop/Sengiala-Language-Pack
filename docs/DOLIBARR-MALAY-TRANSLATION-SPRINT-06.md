# Dolibarr Malay Translation Sprint 06

## Purpose

Sprint 06 expands the Bahasa Melayu Malaysia language pack for manufacturing, bill of materials, material requirements planning, manufacturing orders, workstations, and product batch tracking.

This sprint builds on Sprint 01 to Sprint 05 terminology decisions and must preserve the approved controlled terminology.

## Scope

Sprint 06 focuses on:

- Manufacturing
- Bill of Materials
- MRP
- Manufacturing Orders
- Workstations
- Product batch and lot tracking

## Target Files

- `lang/ms_MY/bom.lang`
- `lang/ms_MY/mrp.lang`
- `lang/ms_MY/mo.lang`
- `lang/ms_MY/manufacturing.lang`
- `lang/ms_MY/workstation.lang`
- `lang/ms_MY/productbatch.lang`

Use the approved terminology from previous sprints:

- Member → Anggota
- Amount → Jumlah

- Warehouse → Stor
- Stock → Stok
- Inventory → Inventori
- Shipment → Penghantaran
- Delivery → Serahan
- Reception → Penerimaan
- Delete → Hapus
- Deleted → Dihapuskan

- File → Fail
- Report → Laporan
