# Cooperative Terminology

Rangka dokumen istilah koperasi Malaysia untuk penyelarasan Finance, Membership dan Governance Foundation.

## Istilah normatif sedia ada

- Member → Anggota
- Membership → Keanggotaan
- Share Capital → Modal Syer
- Bonus Share → Syer Bonus
- Patronage → Potongan Langganan
- Patronage Bonus → Bonus Langganan
- Appropriation → Pembahagian Keuntungan
