# Dolibarr Malay Translation Sprint 03

## Purpose

Sprint 03 expands the Bahasa Melayu Malaysia language pack for user management, access control, security, basic HR, and leave management.

This sprint builds on Sprint 01 and Sprint 02 terminology decisions and must preserve the approved controlled terminology in `docs/TERMINOLOGY-STANDARD.md`.

## Scope

Sprint 03 focuses on:

- Users
- Groups
- Permissions and access rights
- Security
- HR basics
- Leave / holiday management
- OAuth / OAuth2 labels

## Target Files

- `lang/ms_MY/users.lang`
- `lang/ms_MY/groups.lang`
- `lang/ms_MY/permissions.lang`
- `lang/ms_MY/security.lang`
- `lang/ms_MY/hrm.lang`
- `lang/ms_MY/holiday.lang`
- `lang/ms_MY/oauth.lang`
- `lang/ms_MY/oauth2.lang`
