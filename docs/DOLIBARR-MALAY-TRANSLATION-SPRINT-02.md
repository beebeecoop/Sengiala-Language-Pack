# Dolibarr Malay Translation Sprint 02

## Purpose

Sprint 02 expands the Bahasa Melayu Malaysia language pack for additional Dolibarr business workflow modules.

This sprint builds on Sprint 01 terminology decisions and must preserve the approved controlled terminology in docs/TERMINOLOGY-STANDARD.md.

## Scope

Sprint 02 focuses on:

- Proposals / quotations
- Projects
- Contracts
- Categories
- Agenda / events
- Mail / email
- Errors and system messages
- Commercial workflow terms

## Target Files

- lang/ms_MY/proposals.lang
- lang/ms_MY/projects.lang
- lang/ms_MY/contracts.lang
- lang/ms_MY/categories.lang
- lang/ms_MY/agenda.lang
- lang/ms_MY/mail.lang
- lang/ms_MY/errors.lang
- lang/ms_MY/commercial.lang

## Controlled Terminology Reminder

Use the approved terminology from Sprint 01:

- Member → Anggota
- Membership Fee → Fi Masuk
- Member Subscription → Caruman Anggota
- Amount → Jumlah
- Invoice / Bill → Invois
- Supplier Invoice → Invois Pembekal
- Warehouse → Stor
- Reconciliation → Penyesuaian
- Adjustment → Pelarasan
- Income Statement → Penyata Pendapatan
- Profit and Loss Statement → Penyata Untung Rugi

## Validation

Before opening the pull request, run terminology and format checks against all .lang files.
