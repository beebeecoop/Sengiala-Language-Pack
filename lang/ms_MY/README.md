# Dolibarr `ms_MY` Language Pack

Folder ini mengandungi fail bahasa Bahasa Melayu Malaysia untuk Dolibarr.

## Status

Foundation Draft — Sprint 01

## Installation concept

Fail dalam folder ini disediakan untuk dipadankan dengan struktur Dolibarr:

```text
htdocs/lang/ms_MY/
```

## Notes

- Format fail `.lang` hendaklah mengekalkan bentuk `Key=Value`.
- Nama key asal Dolibarr tidak boleh diterjemah.
- Hanya nilai selepas `=` diterjemah.
- Istilah koperasi hendaklah mengikuti `docs/TERMINOLOGY-STANDARD.md`.
